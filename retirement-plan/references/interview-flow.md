# Interview flow

Short, mobile-friendly. **Skip anything already known** from documents, past conversations, user memory, or the prior `retirement-plan.html`. Use multiple-choice tools where available. ≤3 questions per turn. Industry terms (PIA, FRA, RMD, SWR) are used without definition — assume finance literacy.

## Order

1. **Identity & timeline**
   - Current age (user, spouse if applicable).
   - Target retirement year or age.
   - Framing the user prefers ("Retire by 50", "Coast by 55", "Work optional at 52", etc.).

2. **Income today**
   - W-2 / primary salary (gross).
   - RSU vest schedule (skip if RSU docs present).
   - Side income (consulting, rentals, royalties, partner's contribution).
   - Expected end date for any of the above (e.g. consulting wind-down age).

3. **Assets** *(skip entirely if statements cover the category)*
   - Brokerage total.
   - Retirement (401k / IRA / Roth / HSA / pension) total + tax-treatment split.
   - Crypto total.
   - Cash / HYSA.
   - Real estate: address-or-label, current value, mortgage balance, rate, payoff date.

4. **Liabilities**
   - Non-mortgage debt (cards, auto, student, HELOC).
   - Target debt-free year if there's an active paydown plan.

5. **Spending & lifestyle**
   - Base annual spending today.
   - Vacation budget per year.
   - Vehicle replacement cadence and typical cost.
   - Healthcare expectation pre-Medicare (if retiring before 65).
   - Annual lifestyle creep assumption (default 1–2%).

6. **Retirement targets**
   - Target spending range in retirement (e.g. `$125–150K/yr`).
   - Big purchases (second home, sabbatical, weddings) with year + cost.
   - Pension drawdown start age, if applicable.

7. **Social Security** *(skip if SS PDF present and < 12 months old)*
   - PIA at FRA for user and spouse.
   - Planned claim ages.

## Sensitive — never surface in fresh interviews

- **Partner health limitations.** If past conversations have flagged a constraint (e.g. "wife can't clean Airbnbs forever, bad neck/shoulder"), encode it silently into knob defaults — for example, default a "wife-stops-cleaning" milestone in the projection. **Do not ask about it.**
- **End-of-life expectancy.** Default the portfolio-survival check to age 95. The user can adjust via knob.
- **Anxiety, mental health, relationship stress.** Out of scope. The artifact is finance, not therapy.

## Defaults when the user shrugs

| Knob | Default |
|---|---|
| Real return | 5% |
| Real RE appreciation | 1% |
| Inflation | 3% |
| SWR | 4% |
| Lifestyle creep | 1.5%/yr |
| Healthcare pre-Medicare | $24K/yr/person, +5%/yr |
| Healthcare post-Medicare | $8K/yr/person, +5%/yr |
| Car replacement | every 8 years × $40K |
| Crash modeling | every 10 years, drop 25% |
| Survival check age | 95 |
| SS claim age | FRA (67) for both |
